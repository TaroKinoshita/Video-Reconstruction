# PLAN v1.1（2026-11-26 再改訂）：映画の複数カットから、カメラに映っていない所まで含めた編集できる空間を作る

前の版（「複数カットを 1 つの編集できる Blender シーンに」）は git の履歴に残る。
関連研究は `docs/RELATED_WORK_2026-11.md`。

## 0. ゴール

> **映画の複数カットのシーンから、カメラに映っていない所まで含めた、1 つの編集できる Blender の空間を作る。
> 映っていない所は、他のカットを手がかりに想像し、隠したカットで確かめる。
> 作り込みは、映画の演出から決めた重要度で配分する。**

使い道：映画のシーンを、元のカメラでは映らなかった角度から撮り直せる（編集した Blender のシーン → V2V）。

## 1. なぜこの方向か（2026-11-25〜26 に確かめたこと）

- **MAVE は、カメラに映っていない所を物として作らない**（ユーザーが MAVE の結果を見て確認）。
- **Opus 5.5（CineRecon の Matrix のシーン）は、7 カットを 1 つの空間・1 つのシーンにまとめている**（7 台のカメラ、共有のセット）。なので「複数カットを 1 つのシーンにまとめる」こと自体は新しくない。
- Opus 5.5 の動作は、関節の位置のずれの中央値が画面幅の 3.5% と小さく、弱点は反り始めの遅れと、その後の倒れすぎ（`runs/movie/v1_1_exp/cinerecon_matrix/pose_metrics.json`）。動作で大きな差を出すのは難しい。
- **SceneAnything は、映っていない所を補い（「推測」と印）、見え方で作り込みを変える**。ただし 1 ショットだけで、人を扱わない。
- → 空いているのは、**複数カットの情報で映っていない所を補い、別のカットで確かめること**と、**映画の演出から重要度を決めること**、それを人を含む映画のシーンでやること。

## 2. 柱

**主：映っていない所まで含めた 1 つの空間**
- 複数カットのカメラを 1 つの空間にそろえ、各カットで見えた物をまとめる。
- どのカットにも映っていない所（カメラの外、物の裏、奥）は、他のカットの手がかり（同じ物の別の面、続く床や壁、建物の並び）から想像して、部品として作る。
- 各部品に印を付ける：**観測済み**（どこかのカットに映っている）／**確認済みの想像**（想像したが、別のカットで答え合わせができた）／**推測**（どのカットにも映っていない）。

**柱 2：隠したカットで確かめる**
- 1 カットを隠して残りのカットだけから空間を作り、隠したカットのカメラで描画して本物と比べる。隠したカットにだけ映っている所は「映っていない所」なので、想像がどれだけ当たったかを測れる。
- 照らすのは止まっている大きな構造（床・壁・縁・建物・大きな物）。人の動きは対象にしない。

**柱 3：映画の演出から重要度を決める**
- アップで撮られた物、何度も映る物、人が触る・乗る物を重要とし、細かく作る。重要でない背景や小物は簡単に作る。
- SceneAnything の「見え方（画面の大きさ・映るフレーム数）」とは別の軸。主の柱を安く・速くする工夫として入れる。
- 重要度の判定は、CineRecon のチェックリストに出てくる物（シーンにとって大事な物）を当てられたかで確かめる。

**人の扱い**
- 人は、MAVE（公開されたら）か Opus 5.5 並みの質で置ければよい。動作の改善は主張にしない。

## 3. 外すもの

- 学習させたモデル（元のコンセプト）：次の段。
- 動作の細かい改善：今回は主張にしない（必要なら、カットの切れ目で人が飛ばない程度）。
- 音。
- V2V：最後の見せ場として 1 本（新しい角度から撮り直す例）。

## 4. 何で「できた」と言うか

- **隠したカットでの再現**：隠したカットのカメラで描画し、本物と比べる。比べる量は、止まっている構造の輪郭・奥行きの順序・物の位置（MAVE の評価の考え方を使う）と、見た目の近さ。比べる相手は、Opus 5.5 の Matrix のシーン（`scene.json`・`cameras.json` があるので同じテストができる）、MAVE（公開されたら）。
- **新しい角度からの見た目**：元のカメラから外れた角度で描画し、空間が欠けていないか、もっともらしいか（人の判断、補助的に AI の判断）。
- **重要度の判定**：CineRecon のチェックリストの物を、重要と判定できた割合。作り込みを配分したとき、同じ手間で再現がどれだけ良くなるか。
- **公開されている評価**：CineRecon（video1 が Matrix の場面）。
- 数字は最低ラインの門。最終判定は人が並べて見て決める。前より良いだけでは採用しない。実行していないことを「確かめた」と書かない。
