# v4 差し戻しの理由と再設計案（2026-11-23）

v4 は不合格。`final` は撤回した（`runs/movie/v4_A/agent/experimental_rejected` に改名）。
v5 として作ったカット1の .blend（`runs/movie/v5_A/cut1`）も、前の出力（体・カメラ・セット）を使い回しているので撤回する。
この文書は新しい .blend ではなく、同じ破綻をどこで止めるかの設計である。

## 0. なぜこの出来で提出したか

元映像・完成レンダー・採用ログ（`runs/movie/v4_A/refine3/refine.json`、`runs/movie/v4_A/agent/notes.md`、
`.../experimental_rejected/look/cut*.jpg`）を並べた結果、提出の理由は一つ：**部品ごとの数字が前より良くなったことを、
ショットが合っていることと取り違えた。** 完成レンダーを元映像と並べて再生し、「このカットで何が起きているように見えるか」を
問う工程が、設計にも私の作業にもなかった。

- **cut 6**：検証点 4 点、採用後も 494 px（画面幅の約 4 割）ずれ。採用条件は「検証点の中央値が前より小さい」だけ
  （`gpu/observe/fit_person.py`：`accept = enough and f["all"] < b["all"]`、`enough` は全カットで 15 点以上）。
  この条件で落とせるのは「前より悪くなる案」だけで、**ずれたままの案・証拠の乏しい案・映画にない顔や腕が映る案は一つも落とせない。**
  完成レンダーでは、元映像はコートの布なのに、大きな顔と腕が入り込んでいる。
- **cut 2**：元映像では、手が銃を握って顔の前に突き出している。出力では、顔の前に直方体が浮き、手は銃から離れている。
  この手は「何もしていない」ように見える。手首の検証点は 0 なのに、銃の位置はマスクの重なりで選び、手との関係は誰も見ていない。
- **cut 4**：背景の点でカメラを直した。それは成果。しかし完成レンダーでは、コートが胴体を覆い、屋上の縁と建物の輪郭が合っていない。
  カメラを変えたのに、セットのスクリプトは v3 のまま（古いカメラで合わせた配置）。カメラのログを根拠にショットを通した＝評価対象の取り違え。

## 2. どの観測で、どの変数を直すか

| 観測（元映像から、推定器とは別経路） | 直す変数 | 見分けられないとき |
|---|---|---|
| 背景の角・稜線（人と動く物を除いた点の軌跡、屋上の縁や建物の稜線） | カメラの位置・向き・レンズ | アップで背景が少ない → カメラ距離は「保留」、後段は確定値として使わない |
| 見えている関節（ViTPose、顔・肩・肘・手首・腰・膝・足首） | 人の姿勢と位置（体型は人物ごとに 1 つ、引きのカットで決める） | 見えていない部位は「保留」。画面外の脚がカメラや体型を決めない |
| 人物の輪郭と、物との遮蔽（SAM の人物・物のマスクの縁、どちらが手前か） | 衣装の外形、セットの部品、小物の向き | 輪郭が煙などで曖昧 → 保留 |
| 手と小物の接触（小物の輪郭と手の位置関係） | 小物の位置・向き（手に付けるか、置くか） | 手が見えない → 小物は観測位置、手との関係は「保留」と明記 |

- 候補は**一度に一つだけ変える**：今のまま／カメラだけ／人体だけ／衣装だけ／小物だけ。同じフレーム範囲で比べる。
- 候補同士が映像上で見分けられない（差が観測の誤差の範囲）ときは**判定を保留**し、その値を後段に確定値として渡さない
  （保留の値には「どの観測が足りないか」を付けて渡す）。

## 3. cut 6 を確実に止める採用条件（ショット単位、完成レンダーに対して）

ショットは、**部品ではなく完成レンダー全体**で、次のすべてを満たしたときだけ通す。一つでも欠けたら差し戻し。

1. **証拠の量と分布**：検証用の点が 30 点以上、3 部位以上、そのショットのフレームの半分以上に散らばっている。
   足りなければ「保留」で、採用も確定もしない。
2. **絶対の誤差**：調整に使っていないフレーム・点で、人の関節の中央値が画面幅の 3%（1280 幅で約 38 px）以内、
   90 パーセンタイルが 6% 以内。背景の点も同様。前より良いかは問わない。
3. **映画にない物が映らない**：人物として描いた画素のうち、元映像の人物マスクの外にはみ出す割合が 15% 以下。
   映画に顔・腕が映っていないフレームに、顔・腕を描かない。
4. **そのショットに欠かせない動き・接触**（各ショットを元映像で見て、先に書き出す。例）：
   - cut 2・3：右手が銃を握り、銃は顔の前でカメラを向く。銃の輪郭と手が画面上で接している。
   - cut 6：画面はコートの布で埋まり、顔・腕は映らない。
   - cut 4：のけぞる体、後ろに翻るコート、胴体は見える。屋上の縁と奥の建物の稜線が映画の位置にある。
   完成レンダーを元映像と並べて連続再生し、これが見えなければ不合格。
5. **組み合わせで悪くならない**：カメラ・人・衣装・セットのどれかを変えたら、同じショットの完成レンダーで 1〜4 をやり直す。

**現行の失敗例への当てはめ（注意：これは文章での当てはめで、条件を実行して確かめたものではない。未実施）**
- cut 6（v4）：1 で不合格（4 点、1 部位）。2 で不合格（494 px）。3・4 で不合格（顔・腕が映る）。
- cut 2（v4）：4 で不合格（手と銃が接していない、顔の前に箱）。
- cut 4（v4）：4 で不合格（コートが胴体を覆う、屋上の輪郭がずれる）。5 で不合格（カメラを変えたのにセットを見直していない）。
→ 三つとも止まる。

## 4. 8 カットの前に、2 カットで効くことを示す

- **cut 4 の短い区間**（例：64〜124 フレーム、背景の点が十分ある区間）：
  今のまま／カメラだけ／人体だけ／衣装だけ（布コートなし・体に沿う服）を一つずつ変えて比較。
- **cut 2**：引き（cut 0）で決めた体型を変えずに、手と銃の位置関係を再現する（銃は手に握らせ、銃の輪郭に合わせる。
  手首が見えない分は保留と明記）。
- 提出するもの：元映像｜v4｜新案を**同じフレーム範囲で連続再生した動画**（静止画を選ばない）と、
  **調整に使っていないフレーム**での 3 の条件の結果。3 の条件を満たさなければ、8 カットには進まない。

（数字の扱い：ユーザーの指示で、数字を「進んだ証拠」として報告するのはやめた。3 の数字は「最低限これを下回ったら差し戻す」
ための門としてだけ使い、合否の最後は連続再生の見た目で決める。）

## 5. 撤回する設計判断

- **仮定**：「部品ごとに、前より良い案を採用していけば、組み合わせた絵も良くなる」。
- **入った場所**：
  - `gpu/observe/fit_person.py` の採否 `accept = enough and f["all"] < b["all"]`（前より小さければ採用、絶対の基準なし）
  - `scripts/v4_refine.py` のカメラの採否 `GAIN = 0.9`（前の 0.9 倍未満なら採用、セットの見直しなし）
  - エージェントの採否（`runs/movie/v4_A/agent/notes.md`：物のマスクの重なりが大きい方を残す）
  - `scripts/v3_run.py`：部品ごとのチェックを並べるだけで、ショットの合否を出さない
- **壊したショット**：cut 6（494 px ずれたまま採用）、cut 4（カメラだけ採用、セット・衣装は破綻のまま）、
  cut 2（重なりの大きい箱を残し、手と銃の関係を壊した）。
- **置き換え**：採否を「部品の相対改善」から「**ショット単位の完成レンダーに対する絶対の条件（3 の 1〜5）**」に変える。
  部品の候補は一度に一つだけ変え、そのたびにショット全体を判定する。判定できない値は保留として後段に渡し、確定値として使わない。
  閾値を変えるだけ・モデルを替えるだけでは、この構造は直らないので、採否の場所そのものを部品からショットへ移す。
