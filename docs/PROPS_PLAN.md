# 小道具（ボール・ラケットなど）の汎用の仕組み

2026-11-14 作成。テニスのボールで「テキストで画面全体を探す」が失敗したのを受けて、競技や物ごとの個別対応にしない形をまとめる。
コードは `src/vrecon/analysis/props.py`（汎用の道具）と `scripts/` の実行スクリプト。

## 考え方

小道具は「体（や道具）とのやりとり」で状態が切り替わる。物の種類が違っても、状態は次の3つしかない。

| 状態 | 例 | 位置・向きの決め方 | シーンでの印 |
|---|---|---|---|
| held（持たれている） | 手の中のボール、ラケット、カップ | 触れている体の部位（手首・足）に付けて、形で向きを合わせる（`held_poses`） | estimated |
| free（宙にある・置かれている） | トス、打球、投げた物、床の物 | 光線への当てはめ：静止 / 放物線 / 直線（`ball_fit`）。奥行きは重力・既知の大きさ・触れていた部位から | estimated |
| unseen（見えない） | 速すぎる、画面外、隠れている | 前後の状態をつなぐ仮説。行き先の候補は LLM が出し、物理と見えているコマで確かめる | hypothesis |

状態の切り替わり（つかむ・離す・打つ・跳ねる）は「物が部位の近くか」と「動きが急に変わったか」で見つける。どちらも物の種類によらない。

## 部品（上から順に作る）

1. **部位の近くで切り抜く（anchored segmentation）** `scripts/props_recut.py`
   - 画面全体をテキストで探すと、似た物（コートに転がる別のボール、遠くの点）を拾う。触れている部位の周りだけを切り出した
     映像（部位を追って動く窓）で SAM に探させ、マスクを元の画面に戻す。窓の外の似た物は最初から入らない。
   - 窓：部位（例：手首）の画面位置を中心に、物が届く範囲（メートルで指定、奥行きから画素に換算）。
   - 区間：物が体から離れそうな区間だけ回す（短いほど速い）。区間は指定するか、部位の急な動き（腕を上げる・振る）から提案。
   - 入力は映像と、シーンにすでにある体の推定だけ（正解は使わない）。
2. **状態の区切り** `props.phases`（未実装）
   - マスクと部位の距離、動きの変化から held / free / unseen を各コマに付ける。今は `split_at_changes`（動きの急変）だけ。
3. **状態ごとの当てはめ** （実装済み、合成で採点済み）
   - held：`held_poses`（形のIoUで向きを探索、前のコマに近い向きを優先）。合成で向きのズレ中央値 1.6–1.9°。
   - free：`ball_fit`（光線、奥行き重み付け、既知の大きさ、部位への anchor）。合成でトス 1.6–3 cm、手の中 35–48 cm、
     打った後 0.8–1.1 m。
4. **見えない区間の仮説** （未実装）
   - LLM が「どこへ向かうか」を出す（例：テニスのサーブなら相手のサービスエリア、サッカーならゴール方向）。根拠を書かせる。
   - 物理（放物線・速さの一般的な範囲）で区間をつなぎ、写っている数コマがあればそれに合うかで採否を決める（数字で検証）。
   - 写っているコマがなければ「確かめられない仮説」として印をつけたまま入れる。
5. **物の表（大きさ・触れる部位）** （未実装、今は値を書き込んでいる）
   - 物の名前ごとに大きさ（テニスボール 0.067 m、ラケット 0.68×0.27×0.03 m …）と、どの部位に触れるか。
     知らない物は LLM に出させ、出所を記録する。

## 確かめ方

  投げる・キャッチ・置く・転がるを足して、テニス以外でも同じ部品が効くかを点数で見る。
