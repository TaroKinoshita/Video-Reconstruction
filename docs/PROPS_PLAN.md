# 小道具（ボール・ラケットなど）の汎用の仕組み

2026-11-14 作成。テニスのボールで「テキストで画面全体を探す」が失敗したのを受けて、競技や物ごとの個別対応にしない形をまとめる。
コード：`src/vrecon/analysis/props.py`（当てはめの道具）、`prop_fit.py`（状態と流れ）、`prop_table.py`（物の表）、
`rig_fk.py`（描かれる体の関節位置）。実行は `scripts/props_recut.py`（部位の近くで切り抜く）と `scripts/fit_props.py`（シーンに入れる）。

## 考え方

小道具は「体（や道具）とのやりとり」で状態が切り替わる。物の種類が違っても、状態は次の3つしかない。

| 状態 | 例 | 位置・向きの決め方 | シーンでの印 |
|---|---|---|---|
| held（持たれている） | 手の中のボール、ラケット、カップ | 触れている体の部位（手首・足）に付けて、形で向きを合わせる（`held_poses`） | estimated |
| free（宙にある・置かれている） | トス、打球、投げた物、床の物 | 光線への当てはめ：静止 / 放物線 / 直線（`ball_fit`）。奥行きは重力・既知の大きさ・触れていた部位から | estimated |
| unseen（見えない） | 速すぎる、画面外、隠れている | 前後の状態をつなぐ仮説。行き先の候補は LLM が出し、物理と見えているコマで確かめる | hypothesis |

状態の切り替わり（つかむ・離す・打つ・跳ねる）は「物が部位の近くか」と「動きが急に変わったか」で見つける。どちらも物の種類によらない。

## 部品（上から順に作る）

1. **部位の近くで切り抜く（anchored segmentation）** `scripts/props_recut.py`
   - 画面全体をテキストで探すと、似た物（コートに転がる別のボール、遠くの点）を拾う。触れている部位の周りだけを切り出した
     映像（部位を追って動く窓）で SAM に探させ、マスクを元の画面に戻す。窓の外の似た物は最初から入らない。
   - 窓：部位（例：手首）の画面位置を中心に、物が届く範囲（メートルで指定、奥行きから画素に換算）。
   - 区間：物が体から離れそうな区間だけ回す（短いほど速い）。区間は指定するか、部位の急な動き（腕を上げる・振る）から提案。
   - 入力は映像と、シーンにすでにある体の推定だけ（正解は使わない）。
2. **状態の区切り** `prop_fit.fit_sphere_track`（実装済み）
   - マスクが接触部位（表の contacts）の画素位置から hand_px 以内なら held、それ以外は free。3コマ未満の held は通過として free、
     free 側の1-2コマの飛び出しは held のまま。free の前後の held が「離した」「つかんだ」。
   - 置いた場合：手が離れた後もしばらく近くにいるので、ボールがすでに静止位置にあるコマまで遡って「置いた」とする。
3. **状態ごとの当てはめ** （実装済み、合成で採点済み）
   - held（棒状）：`held_poses`（形のIoUで向きを探索、前のコマに近い向きを優先）、その後 `smooth_dirs`（時間方向のガウス、
     sigma 1.5 コマ）。合成で向きのズレ中央値 1.6–1.9° → 1.2–2.0°、コマ間のがたつき 1.2–1.6° → 0.2°。テニスのがたつき中央値
     1.7° → 0.4°。切り抜きのないコマは前後の当てはめた向きの間を補間（以前は近いコマの向きのまま止めて、急に飛んでいた）。
   - held（球）：ボールの画素の光線上、接触部位の奥行き。合成（投げてキャッチ・置く）で 1.4–2.1 cm。
   - free：`ball_fit`（光線、奥行き重み付け、既知の大きさ、離した点・つかんだ点への anchor、離した瞬間の手の速度を事前情報）。
     合成でトス 1.6–3 cm、投げてキャッチ 1.8 cm、置いた後 0.7 cm、手の中で止まっている（接触なし）35–48 cm、打った後 0.5–1.1 m。
   - 時刻：コマの複製（24→30 fps の水増し）は周期があるときだけ複製とみなして本当の時刻を付ける（`props.frame_times`）。
   - 描かれる体の手：接触部位は GVHMR の光線上の点ではなく、シーンが描く体の関節（`rig_fk.posed_joints`）。光線上の点だと
     奥行きが 0.2–0.5 m ずれ、横から見ると物が手から離れる（テニスで発見）。
4. **見えない区間の仮説** `prop_fit.carry_on` / `fill_unseen`（一部実装）
   - free の後で見えなくなったら物理で延ばし、棒状の物の打点（表の strike_frac）が軌道に来たら「打った」。来なければ次の 1.5 秒で
     打点が一番高いコマを打った瞬間とする（仮説）。
   - 打った後の行き先と速さは呼び出し側の JSON（`--after`、例 `runs/venue/tennis/tennis_after.json`：サービスエリアへ 45 m/s）。
     今は人が書いた。LLM に書かせる部分は未実装。写っているコマとの照合も未実装。
   - それ以外の見えないコマは、一番長く持っていた部位に持たせる（仮説）。
5. **物の表** `prop_table.py`（実装済み）
   - 形（sphere / stick）、大きさ、触れる部位、部位からの距離、打点、色、出所。テニス・野球・サッカー・バスケ・ゴルフ・卓球、
     カップ、スマホ。表にない物は JSON で足す（`--table`、出所も記録）。LLM に書かせるのは未実装。
