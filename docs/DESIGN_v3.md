# DESIGN v3：測った証拠 ＋ AI が組む ＋ 証拠で検証（2026-11-23）

v2 までのパイプラインは「解析結果をそのまま形にする」作りで、ノイズがそのまま形・動きになった
（箱と板の寄せ集め、瞬間移動する物、棒のマネキン）。CineRecon（arXiv 2610.16577）と MAVE（arXiv 2611.22464）を読んだうえで、
作りを次のように変える。

## 調べて分かったこと

| | CineRecon | MAVE | v2（今まで） |
|---|---|---|---|
| シーンを作るのは | AI エージェント（Claude Code / Codex CLI、Blender MCP） | AI エージェント（Blender コードを書く） | 解析結果を機械的に変換 |
| 測定 | なし（AI が目で見るだけ） | カメラ・奥行き・人の体を先に測り、1つのメートル世界に | 同（4RC・GVHMR・FAB・SAM 3.1） |
| 固定するもの | なし | カメラと人のポーズ（人は「リグ付きマネキン」） | すべて解析結果のまま |
| 確認 | AI が元映像と描画を並べて見比べ、直す（これが最も効く：なしだと 76.6→66.4） | 証拠に基づく機械チェックを毎回返し、解決か理由付けまで提出させない | 自動チェックは点数を出すだけ |
| 最高点 | Opus 5.5 で 76.6（3設定平均） | GPT-6.1 Sol で 76.1（素の AI 48.6） | — |
| 複数カット | 1本の動画に複数ショットあり（扱いは記載なし） | 1ショットのみ | 1つの世界にまとめる（強み） |

- MAVE で一番効いたのは「人の体を測って固定」（外すと総合 -12.0）。次が「奥行き証拠」。確認ループ自体は -2.2。
- CineRecon で一番効いたのは「描いて元映像と見比べて直す」繰り返し。
- どちらも、形はエージェントが「名前付きの、意図のある部品」で作る。数は少なく（MAVE は素の AI の 1/3）。

## 新しい作り

```
1 観測（今のパイプラインを流用）           2 AI が組む（新）                          3 証拠で検証（新）
カット・SAM 3.1・GVHMR/FAB・4RC・合成 →  証拠パック（固定する物＋参考の証拠）  →  道具 API で部品を置く・描く・見比べる  ←→  verify(): 機械チェック
                                                                                    submit(): 未解決があれば却下
```

### 1 証拠パック（evidence）
固定（AI は変えられない）：
- カメラ：カットごとの経路・レンズ・切り替え（タイムラインのマーカー）。
- 人：体の関節の動き（GVHMR / FAB / アップの当てはめ）。AI ができるのは MAVE と同じく「人ごとの大きさ1つ」と「消す（理由付き）」だけ。
- 床：z = 0。

参考（AI が使う・使わないを決める）：
- 背景の平面（壁・床・天井の候補、v2 の layout）と点群の要約、低い壁。
- 物の観測（SAM 3.1 の語・位置の中央値・大きさ・手に持つか）。関門（gate）を通した後のもの。
- 各カットのキーフレーム画像。

### 2 道具 API（`src/vrecon/scene/agent_api.py`、bpy はここだけ）
AI は Python で次を呼ぶ（生の bpy は使わせない＝崩れにくい）：
- `part(name, shape, center, size, rot, category, color, parent=None)`：box / cylinder / plane / sphere / cone / wedge
- `prop(name, kind, ...)`：銃・椅子・手すりなどの種類別の形（`scene/props.py`）
- `animate(name, keys)`：部品の動き（物を投げる、ドアが開くなど）
- `group(name, parts)`：「ビル」「屋上の縁」のようなまとまり
- `remove(name)` / `scale_person(id, s)` / `hide_person(id, reason)`
- `look(cut, frames)`：元映像と描画を並べた画像を返す（AI が見比べる）
- `verify()`：下の機械チェックの文章レポート
- `submit()`：未解決のチェックが「解決」か「理由付き」になっていなければ却下

### 3 機械チェック（verify）
v2 の数値チェックを、AI に返す文章レポートに変える：
- 奥行きの矛盾：部品が、観測された人・物の手前に来て隠している（MAVE の遮蔽率）
- 証拠の取りこぼし：測れた壁・床・低い壁の近くに部品がない（MAVE の coverage）
- 人と周囲：体が部品にめり込む・足の下に支えがない
- 浮いた・重複した・孤立した部品
- 瞬間移動・一瞬だけの物（gate と同じ規則）
- 2D の重なり：人・物の切り抜きとの一致（カットごと）

### 人の見た目
棒のマネキンをやめ、関節から作る滑らかな人型（SMPL の形、または丸い部品の人形）にする。
姿勢は測ったまま固定。

### エージェントの実行
- まず Claude Code のサブエージェント（CineRecon で最高点の Opus 系と同じ環境）で回す。費用は今のセッションの利用枠。
- 後で fal 経由の別モデル（GPT-6.1 Sol など）にも差し替えられるよう、道具 API はモデルに依存しない。
- 予算：1本 15〜30 分（MAVE：15 分以上は伸びない）。

## 比べ方
- 素の AI（測定なし・同じ道具 API、CineRecon と同じ条件）と、v3（証拠つき）を同じチェックで比べる。
- 判定：v2 の 2 つのチェック（数値・AI 判定）＋ CineRecon 型の項目別判定（カメラ・物・関係・動作）。

## 残すもの・やめるもの
- 残す：観測の全工程、合成（1つの世界）、gate、2 つのチェック、FAB。
- やめる：解析結果からの自動の形づくり（layout の板・箱、LLM が足すだけの JSON、物の自動配置）は「参考の証拠」に格下げ。
