# 設計レビューのお願い（2026-11-23）

あなた（レビュアー）へ：このプロジェクトは出力の質が低く、作り手は「根本的に何かおかしい」と感じています。
部分的な直し方ではなく、**設計のどこが根本的に間違っているか**、**作り直すなら何をどの順で作るべきか**を、
率直に指摘してください。研究用・非商用です。

## 目的
- 映画のクリップ（複数カット、例：Matrix の屋上シーン 8 カット・約 18 秒）から、**編集できる Blender シーン**を作る。
  - カメラ（カットごとの経路・レンズ）、人（形と動き）、物、セット（床・壁・建物）。
- それをもとに V2V（動画から動画への生成）用の制御動画（深度・ラベル）を出す。
- 目標：素の LLM が Blender を組む場合や、CineRecon（https://cinerecon.github.io/）より目に見えて良いこと。
- 縛り：どの動画にも同じ仕組みで効くこと（クリップごとの手直しはしない）。手元は RTX 4060 Laptop（VRAM 8 GB）。

## 今の作り（v2 パイプライン＋v3 のエージェント）
観測（カットごとに別々に推定）：
1. カット検出 → カットごとの動画
2. SAM 3.1：人のマスク、固定の語リストで物のマスク
3. 人の体：全身が見えるカットは GVHMR（関節 22 点、世界座標）、アップは FAB-L（SAM 3D Body 系、1 フレームずつ）
4. カメラと点群：4RC をカットごとに実行 ＋ 複数カットのキーフレームでもう一度 4RC（つなぐため）
5. つなぐ：カット同士を 1 つの世界（メートル、Z 上、床 z=0）に並べる
6. アップのカットは「同じ人の体」に合わせてカメラ位置を探索して置く
7. セット：点群から平面・低い壁・箱を検出（layout）
8. 物：マスク＋深度で位置、手に持つ物は手首に付ける
9. gate：一瞬だけ・瞬間移動する物を捨てる、置き物は中央値で止める（時間方向の妥当性）
10. 人の見た目：関節 → SMPL を IK で当てはめ（カットごとに、関節点に合わせる）→ マスクとの重なりで服の厚み・コートの裾を選ぶ
11. 男女判定：画像 AI で man/woman/child を判定して SMPL のモデルを選ぶ

v3（MAVE / CineRecon に寄せた部分）：
- 上の観測結果のうち **カメラ・人・床を「証拠」として固定**し、AI エージェント（LLM）が Python の小さな API
  （part / prop / animate / visible / remove / hide_person）でセットと物を組む。
- 実行ごとに「映画｜描画」の比較画像と機械チェック（浮き・めり込み・取りこぼした平面・マスクとの重なり・深度の矛盾）を返し、エージェントが直す。

## 結果（Matrix A, 8 カット）
- 自動チェック（人・物のマスクとの重なり−空白、0〜1）：カットごとに 0.34〜0.87、平均 ≈ 0.5。
- AI 判定（GPT-6.1 Sol、0〜5、4 項目）：v2 2.62、v3 2.52、素の LLM 1.55。セットは v3 が少し良く、物は v3 が悪い。
- 人が見て：「カメラがガタガタ」「物が微妙」「人が太っている」「動きがぎこちない」。質が低い。

## 測って分かっていること
- 測った骨格が、標準の SMPL 男性より小さい（骨盤〜首 0.43〜0.45 m vs 0.53、肩幅 0.26〜0.30 vs 0.39）。
  アップ（FAB）のカットは同じ人なのに比率が大きく違う（首〜頭 0.07〜0.09 vs 引き 0.16〜0.17）。
  → 標準の大きさの体を小さな骨格に押し込み、胴がつぶれて太って見える。体型（betas）は当てはめでほぼ動かなかった。
- 人の身長（関節の高さ）が 1.24〜1.50 m（実際は 1.8 m 前後）。世界の縮尺か体の推定がずれている可能性。
- カメラ：カット内のブレは数字上ほとんどない（2 階差分 1〜5 mm/フレーム、回転のブレ 0.01〜0.17°/フレーム）。
  それでも見るとガタついている → カットのつなぎ目、カメラと人のずれ、縮尺のずれが疑わしいが未確認。
- カット 4 の体の関節は 1 フレームあたり平均 4 cm 震える（2 階差分）。
- 多くの工程が「前の工程の出力を正しいものとして固定」して積み重なっている（推定 → つなぐ → 合わせ直す → 捨てる → かぶせる）。
  全体を映像に対して同時に最適化する工程はない。

## 参考にした研究
- CineRecon（arXiv 2610.16577）：測定なし、AI エージェントが Blender MCP でシーンを組み、描画と元映像を見比べて何度も直す。Opus 5.5 で 76.6。直す繰り返しを外すと 66.4。
- MAVE（arXiv 2611.22464）：先にメートル単位で測る（深度・SAM3・SAM 3D Body）→ カメラと人を固定 → エージェントがプリミティブ API で組む → 証拠に基づく検証。人の体の扱いを外すと −12。1 ショットのみ。

## 聞きたいこと
1. 根本的に間違っている設計判断はどれか（例：カットごとに別々に推定してから後でつなぐ、関節点を先に作って後から体をかぶせる、観測を「固定の証拠」にする、など）。
2. 人について：1 人 1 体（形を共有）で、映画全体の映像（マスク・2D 関節）に SMPL を直接合わせる作りに変えるべきか。8 GB VRAM で現実的な方法・既存の道具は何か。
3. カメラについて：ガタつきの原因として何を最初に疑うべきか。カットごとの 4RC をやめて、別の方法（例：全体の SfM、カメラの動きの型を判定してなめらかにする）にすべきか。
4. 縮尺：人の身長が 1.2〜1.5 m になる。世界の縮尺をどう決めるべきか（人の標準身長を基準にする、深度モデルに合わせる、など）。
5. 物とセット：エージェントに組ませる方向（CineRecon / MAVE 型）は正しいか。観測と AI 判断の役割分担はどうあるべきか。
6. 作り直すなら、最初の 2 週間でやるべきことを順番に。捨てるべき工程も挙げてほしい。
7. 評価：今の評価（マスクの重なり＋AI 判定）は、人が感じる質を測れていない。何で測るべきか。
